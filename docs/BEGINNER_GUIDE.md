# MBMS Beginner Guide

This platform is built for construction delivery teams, field officers, and clients. The product is designed to guide each user through the same core flow: enquiry, visit, survey, review, and publication.

## 1) Start from the login page

Open the app and choose the correct portal:

- Staff Portal: for architects, project coordinators, and management
- Field Officer App: for site visits and surveys
- Client Portal: for project tracking and published updates

Each choice routes the user into their own workflow and dashboard.

## 2) Follow the product flow

### Staff workflow

1. Review enquiries in the inbox.
2. Confirm booking details and schedule the visit.
3. Open the project and move it through planning and acceptance stages.
4. Collect or review field survey information.
5. Review reports and approve them.
6. Publish approved content to the client portal when ready.

### Field officer workflow

1. Open your visits list.
2. Check in for the assigned visit.
3. Complete the site survey.
4. Submit findings so staff can review the report.

### Client workflow

1. Open the portal dashboard.
2. Review the project list.
3. Open a project to see status updates and published outputs.
4. Check only the project content that has been explicitly published to you.

## 3) What each main action does

- Open inbox: view enquiries and active conversations
- All projects: review the whole project pipeline
- Refresh: reload the latest project and visit data
- Visit details: inspect the visit record and status
- Check in / Check out: mark the field visit lifecycle
- Start survey: begin a field survey for the booking
- View project: open the client-visible project summary
- Publish: make approved work visible to the client portal

## 4) Key business rules

- Enquiries are separate from projects.
- A booking becomes part of a project workflow.
- Approval and publication are separate actions.
- Published work is visible to the client, while internal review remains restricted.
- The platform supports role-based access to keep staff and client data separated.

## 5) Recommended first-time path

If you are new to the product, do this in order:

1. Log in as a Staff user.
2. Open the inbox and check the latest enquiry.
3. Confirm a booking and review the project.
4. Visit the field view and complete a survey.
5. Review the report and publish once approved.
6. Open the Client Portal to see the published outcome.

This sequence demonstrates the full lifecycle of the platform.
